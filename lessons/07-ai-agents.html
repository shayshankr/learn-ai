AI Agents

A chatbot answers one question at a time. An agent keeps working — using tools, checking its own results, and taking several steps toward a goal.

Chatbot vs. agent

💬 Plain chatbot

You ask, it answers using only what it already knows. One turn, done. If it needs current information or to actually do something, it can't.

🤖 Agent

Given a goal, it plans steps, uses tools (search the web, run code, read a file, call an API), looks at the result, and decides what to do next — on a loop, until the goal is done.

Watch the loop run

This is the core pattern behind every AI agent — including the one writing this course. Press play to step through it for a real task.

Goal: "Find out if it's going to rain tomorrow and draft a message to reschedule the picnic if so."

Where you'll meet agents

⌨️

Claude Code / Cursor Agent

Plans and executes multi-file coding tasks, running commands and tests along the way.

🌐

Browser agents

Can click through real websites — booking, form-filling, research — on your behalf.

🔌

MCP (Model Context Protocol)

An open standard letting agents plug into tools like Slack, GitHub, or a database safely.

⚠️ More capability, more care needed

An agent that can actually click "send" or "buy" is more useful — and riskier — than one that can only talk. Good agent tools ask for confirmation before doing anything irreversible (sending money, deleting files, posting publicly). Be wary of any tool that doesn't.

🎯 Try it for real

Give a real agent a small multi-step task — "research X and summarize the top 3 findings" or, if you code, "fix this bug and explain what was wrong" — and actually watch it think, act, and check its own work.
