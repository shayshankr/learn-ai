AI Coding Assistants

For anyone who writes code — or wants to start. These tools read and write code alongside you, in your actual editor.

The landscape

🧑‍💻

GitHub Copilot

  • Autocompletes as you type
  • Built into VS Code, JetBrains
  • Great first tool to try
📝

Cursor

  • A full editor built around AI
  • Can edit multiple files at once
  • Popular for building whole projects
⌨️

Claude Code

  • Runs in your terminal
  • Can plan, edit, run commands, test
  • Good for larger, multi-step tasks
🌐

Replit / v0 / Bolt

  • Browser-based, no setup
  • Describe an app, get a working start
  • Best for absolute beginners

See it in action: before → after

Click "Ask the assistant" to see the kind of fix an AI coding tool would suggest for a small, real bug.

Before 
function getTotal(items) {
  let total;
  for (let i = 0; i <= items.length; i++) {
    total += items[i].price;
  }
  return total;
}
🔧 What the assistant caught

total starts undefined instead of 0, and i <= items.length reads one item past the end of the array. Both would crash or return NaN — the kind of bug that's easy to miss reading quickly, but obvious once pointed out.

Good habits from day one

💡 Treat it like a fast junior collaborator

It writes quickly but doesn't know your intent unless you tell it. Review what it changes, run the code, and ask it to explain anything unfamiliar — don't paste-and-hope.

⚠️ Never paste real secrets

Don't paste API keys, passwords, or production database credentials into any AI chat — treat prompts like they might be logged somewhere.

🎯 Try it for real

If you write any code at all, install a free AI coding tool and point it at something you're actually stuck on — a bug, an error message, or code you don't understand. Ask it to explain before it fixes.
