Agents on Real Work

Lesson 7 showed you the think → act → observe loop on a toy example. This is the same loop on something that actually matters, and the one habit that keeps it safe.

Bigger tasks, same loop

A coding agent working across a real, multi-file project isn't doing anything conceptually different from the weather-and-picnic example in Lesson 7. It's just running that loop more times, on higher-stakes ground: editing real files, running real commands, sometimes touching real accounts.

The one thing that changes is what "observe" needs to include: not just "did that work," but "was that safe to do without asking first."
