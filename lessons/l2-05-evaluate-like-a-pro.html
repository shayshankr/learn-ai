Evaluate AI Output Like a Pro

Lesson 8 taught you that hallucinations exist. This is the actual checklist for catching them, the same one worth running on anything you're about to rely on.

The five-point checklist

🔗

Source it

Can you find where this claim comes from, independently of the AI that said it?

🔀

Cross-check it

Ask a second model the same question. Disagreement is a signal to dig further.

🧪

Test the edge

Does an "always true" rule survive an obvious exception you can think of?

🔢

Check the math

Re-derive any specific number yourself instead of trusting the total.

✨

Reread the confident part

The smoothest-sounding sentence is often the one most worth double-checking.

Score yourself: three claims

Run the checklist mentally on each one. Pick fabricated or real.

1 / 3 — "The Great Wall of China is visible from space with the naked eye."

🎯 Try it for real

Next time an AI hands you a surprising or specific claim, run the five-point checklist on it once, for real, before you repeat it to anyone.
