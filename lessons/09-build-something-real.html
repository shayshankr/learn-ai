Build Something Real

Eight lessons of using AI tools. This one is different: pick something small, build it with an AI coding assistant, and put it on the internet.

Pick a project

Nothing ambitious. Something you could finish this week. Click one to see the brief and a starter prompt you can paste straight into Claude Code, Cursor, or Replit.

A tiny tracker

A single page that tracks something daily — habits, expenses, mood — saved right in your browser. No backend, no database, no login.

📋 Starter prompt

Build me a single-page HTML app that lets me log a daily habit (yes/no) with a running streak counter. Store everything in localStorage, no backend. Make it look clean, and show me a preview before we polish it.

The loop you're about to run

This is the same shape as every lesson before this one, except now you're the one doing it, not watching a demo.

Ship it somewhere real

A working thing on the internet beats a perfect thing on your laptop. Pick whichever of these feels least intimidating.

📄

Netlify Drop

Drag your project folder onto netlify.com/drop and get a live URL in seconds. No account, no git. Easiest first deploy.

🐙

GitHub Pages

What this course itself runs on. Push to a public repo, flip on Pages in Settings. Best once you're comfortable with git.

▶️

Replit

Build and host in the same place. One click to publish if you started the project there already.

⚠️ The most common way this stalls

The AI fixes a bug, creates a new one, fixes that, breaks the first one again. If you notice the same error coming back twice, stop asking for another fix. Instead ask it to explain what the code is doing right now, in plain language. If that doesn't unstick things, it's fine to undo the last change and try a more specific prompt instead of pushing forward.

🎯 Try it for real

Give yourself 90 minutes this week. Pick one idea above, get it running, and deploy it somewhere real, even if it's rough around the edges.
