Prompt Engineering

Same AI, wildly different answers, depending on how you ask. "Prompt engineering" sounds fancy — it's really just learning to ask clearly.

The four ingredients of a good prompt

Not every prompt needs all four, but knowing them helps you diagnose a bad answer.

🎯

Task

What do you actually want it to do? Be specific about the output — an email, a list, code, a table.

🧩

Context

Background it needs but can't guess — your audience, constraints, what you've already tried.

📐

Format

How should the answer look? Bullet points, a short paragraph, a table, code only?

🎭

Tone/Role

Optional, but useful — "explain like I'm new to this" vs "write as a senior engineer."

⚠️ One habit worth building

If the first answer isn't quite right, don't start over — just reply with what's wrong: "shorter," "less formal," "add an example." Treat it as a conversation, not a vending machine.
